5

FlagAnswers


--source=.this folder (omit for an empty repo)


--publicwho sees it (--private otherwise)


--pushupload now (omit to push later)


--remote=originthe short name you push to


--descriptionwhat it is




Flags go in any order. Only the repo name is positional.

4

Resolve it

your version
=======
what is already on main
>>>>>>> main


Usually you keep both. Edit the file, delete the
three marker lines, then:




git add is how you say resolved. Panicking?
git merge --abort puts everything back.

Help






What you seeFix



Permission denied on push, Phase 2
    You cloned ours, not your fork:

    git remote set-url origin https://github.com/{{user}}/git-started.git



Permission denied on push, Phase 3
    Invite not accepted:
gh api user/repository_invitations
    then gh api -X PATCH user/repository_invitations/ID



'add.' is not a git command
    git add . with a space



unknown command "accept" for "gh repo"
    It does not exist. Use the invitations API, or accept in the browser.



fatal: not a git repository
    cd into the project folder. pwd shows where you are.



error: pathspec did not match
    Missing -c: git switch -c add-{{name}}



PR opened against your own fork
    Add --repo accelerate-muj/git-started



remote upstream already exists
    Harmless. Ignore it.



! [rejected] main -> main
    git pull origin main then push again



CONFLICT (content): Merge conflict in ...
    Expected in Phase 3. Keep both, delete markers, git add ., commit.



Leftover <<<<<<< in the file
    Search for <<< and delete every marker line



refusing to merge unrelated histories
    git pull origin main --allow-unrelated-histories



"There isn't anything to compare"
    You committed to main. Branch and push that instead.



gh pr merge fails
    PR still has conflicts. Author fixes first.



Password asked for and rejected
    gh auth login, say yes to the git credentials question



gh: command not found
    Close the terminal, open a new one



Stuck in an editor you cannot exit
    It is vim. Esc then :wq then Enter.



Want to undo and start again
    git merge --abort. Nothing is lost.





Nothing matches? Run git status.
It cannot break anything and it tells you where you are. Then put your hand up.
