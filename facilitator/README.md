# Facilitator notes

Material for whoever is running the session. **Deliberately not in the participant
handbook**, because if people can read the reasoning off a page, the workshop is
just somebody reading aloud what everyone already has.

The split:

| | Participants get | You get |
|---|---|---|
| [The handbook](https://accelerate-muj.github.io/git-started/) | The commands, one line of context each, and the troubleshooting table | |
| This folder | | The story, the pauses, the questions to ask, the callbacks |

| File | What |
|---|---|
| [phase-1-script.md](phase-1-script.md) | The opening. Why version control exists, told through one poem and a folder full of `_final` files. |

## Timing

| Block | Minutes |
|---|---|
| Chaos Draft warm-up | 15 |
| Phase 1 opening (the story) | 8 |
| Phase 1 hands on | 30 |
| Phase 2 | 40 |
| Phase 3 | 50 |
| Rabbit Holes, what next | 5 |

Buffer generously in Phase 2. Somebody will clone the wrong repo, and somebody
will forget `--repo` on their pull request. Both are in the handbook's Help table,
so point rather than solve.
