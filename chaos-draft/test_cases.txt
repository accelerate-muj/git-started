# Labelled test cases for the filter.
#
# Used by test_filter.py and by the tier-1 checks. This is DATA, not code: the point
# of keeping it in its own file is that test_filter.py stays readable, and this file
# can be extended by anyone without touching Python.
#
# FORMAT
#
#   [block:category]   every word under this heading MUST be blocked
#   [allow:category]   every word under this heading MUST be allowed
#
# The category is only used to group the output, so a failure report tells you
# *what kind* of thing broke rather than just listing words.
#
# The allow sections matter as much as the block sections. A filter that eats
# "class", "coming" or an ordinary Hindi word stops the activity dead, which is
# a worse failure than missing something.
#
# This set is deliberately INDEPENDENT of wordlist.txt. Testing a dictionary
# against itself proves nothing, so add cases here that you think might fail,
# not cases you know already pass.
#
# Comments start with #. Blank lines are ignored.
