# Tier 1: the dictionary.
#
# The first and most important line of defence. Deterministic, answers in
# microseconds, and unlike the AI tier it never changes its mind.
#
# THREE SECTIONS, and the difference matters a great deal.
#
#   [allow]      Never blocked. Checked before everything else, so it overrides
#                both sections below. This is how ordinary words that happen to
#                contain a blocked root survive. "chudail" means witch.
#
#   [exact]      Must match the WHOLE word after normalisation. Use this for short
#                terms whose letters appear inside innocent words. "ass" belongs
#                here, because otherwise "class", "pass" and "grass" all get eaten.
#                Most entries belong here.
#
#   [contains]   Matched ANYWHERE inside the word. Only for long, unambiguous roots
#                that cannot appear inside anything harmless. "madarchod" belongs
#                here, so all forty spellings die to one entry. Anything shorter
#                than about seven characters here will cause false positives.
#
# NORMALISATION runs before matching, so do NOT list variants with leetspeak,
# punctuation, accents, stretched letters, or long-vowel spellings. All of these
# already hit the single entry "chutiya":
#
#   chutiya   ch00tiya   c-h-u-t-i-y-a   CHUTIYAAAAA   ch@t1ya   chootiya
#
# DO NOT put ordinary words in here. Three were caught and removed during testing:
#   "aand"  folded to "and"      the most common word in English
#   "behen" simply means sister
#   "pen"   was scooped up with the Punjabi terms
# After editing, always run:  python filter.py --collisions
#
# Comments start with #. Blank lines are ignored. Edit during a session and the
# server reloads on the next word submitted.
