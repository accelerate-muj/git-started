# Signatures

Everyone who has been through this workshop signs here.

This file exists for one reason, and it is the opposite of the reason
`poems/` exists. In `poems/` you get a file to yourself, named after your GitHub
username, so that no two people can ever touch the same line and nothing conflicts.
Here, everybody writes to the same block, at the same insertion point, on purpose.

Subphase 2.11 uses this file. Two people add their name as the first line under
`## Signed by`, both open a request, and the second one is refused. That refusal is
the point. Do not try to make it not happen.

Add your name as the **first** line of the list, in this format:

```
- <your-github-username>, <the date>
```
