# poems

One file per person. Name it after your GitHub username:

```
phase-2/poems/<your-github-username>.md
```

That rule is the entire reason this phase runs without conflicts. Usernames are
unique on GitHub, so no two people can ever create the same file, so no two pull
requests can ever touch the same line.

Write whatever version of Sonnet 18 you like in it, and sign it on the last line:

```
Written by <your-name>
```

The signature goes at the end of **your own** file. Not `poem/sonnet-18.md`, and not
anywhere else. Thirty people appending a line to one shared file is a merge conflict
thirty times over, which is a genuinely useful thing to experience and is exactly
what Phase 3 is for.

Do not edit anybody else's file. Do not rename `EXAMPLE-theqmlguy.md`. If you want
to change something outside your own file, that is Phase 3.
