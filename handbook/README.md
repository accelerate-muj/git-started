# Rabbit Holes

The handbook. It picks up where the workshop stops, at **Phase 4**, and keeps going
through everything git and GitHub can do that three hours in a room cannot cover.

It is built as a set of PDFs, one per phase, so they can be handed out separately.

Build them yourself:

```bash
cd handbook && make
```

Requires a TeX distribution. Source is in [`src/`](src/).
